# Support

Use GitHub issues once the public repository is available.

## Bug Reports

Include:

- `bioartifact` version or commit
- Python version
- operating system
- exact command
- JSON output
- a minimal input file or fixture that reproduces the issue

Do not include private or human-subject data in public issues.

## Feature Requests

Describe:

- the artifact type or contract
- why existing inspectors/contracts are insufficient
- expected JSON fields
- downstream workflow or agent decision that needs the feature

Feature requests that preserve lightweight structural validation are more likely
to fit the project than requests for biological interpretation or heavy workflow
orchestration.
