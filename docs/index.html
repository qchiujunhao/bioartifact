Agent-friendly bioinformatics validation

bioartifact

A lightweight Python package and command-line tool for inspecting bioinformatics outputs, validating named contracts, and emitting deterministic JSON for agents, workflows, benchmarks, and reproducibility pipelines.

View repository See CLI examples

What it does

Structured checks for workflow artifacts

bioartifact focuses on structure, compatibility, and downstream usability. It does not interpret biological meaning or replace format-specific tools.

Inspect files

Detect artifact type and summarize readable structural properties.

Validate contracts

Check files against named requirements such as FASTQ, VCF, or narrowPeak.

Validate manifests

Assert expected workflow outputs, contracts, and required companion files.

Expose schemas

Discover JSON schemas and contract metadata directly from the CLI.

Supported artifacts

Common bioinformatics outputs

Current inspectors cover sequencing reads, reference sequences, alignments, variants, genomic intervals, annotations, tables, and lightweight HTML reports.

  • FASTQ
  • FASTA
  • SAM
  • BAM
  • VCF
  • BED
  • narrowPeak
  • GTF
  • GFF

Machine-readable interface

JSON by default, schemas on demand

Every command emits JSON by default. Public schemas pin schema_version, and discovery commands describe available artifact types, contracts, arguments, and schemas. 

$ bioartifact contracts
$ bioartifact types
$ bioartifact schema
$ bioartifact schema contract_result
{
  "name": "paired_fastq",
  "artifact_types": ["fastq"],
  "required_arguments": ["mate"],
  "output_schema": "contract_result"
}

Quickstart

Install and validate

Install

pip install bioartifact

Inspect an artifact

bioartifact inspect sample.bam

Validate a contract

bioartifact validate peaks.narrowPeak \
  --contract narrowpeak

Validate workflow outputs

bioartifact validate-manifest \
  workflow_manifest.json

Workflow manifests

Check expected outputs and companion files

Manifest validation can require companion artifacts such as BAM indexes or tabix indexes. Requirement failures are summarized under summary.requirements. 

{
  "outputs": [
    {
      "name": "alignment",
      "path": "aligned.bam",
      "type": "bam",
      "contract": "sorted_bam",
      "requires": [
        { "name": "bam_index", "suffix": ".bai" }
      ]
    }
  ]
}
